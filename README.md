# Zongertinib-Adults

This repository contains all data files and model files for a PBPK model of zongertinib in healthy adults in GastroPlus. This manuscript describing this model is entitled "Physiologically Based Pharmacokinetic Modeling and Drug-Drug Interaction Screening of Zongertinib in Adults" by Lishuang Wang and Zhoumeng Lin. This manuscript is under review.
